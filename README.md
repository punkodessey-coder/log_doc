# DocFlow
Хранилище документов в стиле GitHub: проекты, папки, версии файлов, ветки, слияние, история, сравнение изменений по строкам и символам, шаблоны папок, роли.

Запуск на Windows: `start.bat [IP] [ПОРТ]` (по умолчанию 0.0.0.0:8000). Нужен Python 3.12 и интернет при первом запуске.
Логин `admin`, пароль выводится в консоли и хранится в `data/config.json` (при первом входе его нужно сменить). Данные — в папке `data/`.
Обновление: замените файлы проекта, папку `data/` оставьте — база обновится автоматически.

Только для администратора: раздел «Журнал» (ошибки и действия, выгрузка .txt), просмотр временных паролей, удаление проекта.

Сравнение версий: PDF (постранично, до/после, карта отличий, увеличение, текстовые изменения), текст и код (построчно и по символам), Word .docx (абзацы + замена рисунков), Visio .vsdx (векторный просмотр «было/стало» с подсветкой изменённых фигур и увеличением), изображения (до/после, карта отличий, регулируемая чувствительность, увеличение). Файлы добавляются выбором, перетаскиванием (в т. ч. папок) и вставкой Ctrl+V.
