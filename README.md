# DocFlow
Хранилище документов в стиле GitHub: проекты, папки, версии файлов, ветки, слияние, история, сравнение изменений по строкам и символам, шаблоны папок, роли.

Запуск на Windows: `start.bat [IP] [ПОРТ]` (по умолчанию 0.0.0.0:8000). Нужен Python 3.12 и интернет при первом запуске.
Логин `admin`, пароль выводится в консоли и хранится в `data/config.json` (при первом входе его нужно сменить). Данные — в папке `data/`.
Обновление: замените файлы проекта, папку `data/` оставьте — база обновится автоматически.

Сравнение версий: текст и код (построчно и по символам), Word .docx (абзацы + замена рисунков), Visio .vsdx (фигуры, текст, положение, связи, картинки), изображения PNG/JPG/GIF/BMP/WEBP/TIFF (до/после и карта отличий). В окне загрузки работает Ctrl+V (скриншоты, файлы, текст) и перетаскивание.
