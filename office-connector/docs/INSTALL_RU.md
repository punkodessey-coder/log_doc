# Установка DocFlow Office Connector (Word / Excel / Visio)

## 1. Схема работы

Надстройка устанавливается на каждый компьютер Windows, где используется настольный Microsoft Office. Она обращается к серверу DocFlow по локальному IP/DNS-имени и использует существующий REST API. Файлы и история версий остаются на сервере; локально хранится только открытый документ и временные загрузки.

Пример адреса: `http://192.168.1.20:8000`.

**Никакого облака или внешнего сервиса интеграции не требуется.** Весь обмен идёт напрямую между компьютером сотрудника и сервером в локальной сети.

## 2. Требования к серверу

1. Разверните DocFlow обычным способом.
2. Убедитесь, что сервер слушает LAN-интерфейс, а не только `127.0.0.1`. Например: `start.bat 0.0.0.0 8000`.
3. Разрешите входящие подключения к выбранному TCP-порту в Windows Firewall только из корпоративной подсети.
4. Проверьте с рабочего компьютера: откройте `http://IP-СЕРВЕРА:ПОРТ/api/health`. Должен вернуться JSON со статусом `ok`.
5. Создайте пользователям DocFlow учётные записи и выдайте доступ к нужным проектам.

Не публикуйте сервер DocFlow в Интернет. В обычной изолированной LAN допустим HTTP; если трафик может перехватываться или сеть не полностью доверенная, настройте HTTPS на reverse proxy и используйте HTTPS-адрес.

## 3. Сборка надстройки

1. Установите Visual Studio 2022.
2. В Visual Studio Installer выберите workload **Разработка классических приложений .NET** (Desktop development with .NET).
3. Установите **.NET Framework 4.8 Developer Pack**.
4. Откройте `office-connector/src/DocFlow.OfficeConnector.sln`.
5. Выберите конфигурацию **Release** и платформу **Any CPU**.
6. Выполните **Build → Build Solution**.
7. Убедитесь, что создан файл `src/DocFlow.OfficeConnector/bin/Release/DocFlow.OfficeConnector.dll`.

Office и надстройка должны иметь совместимую разрядность. Для Any CPU предпочтительно собирать без принудительной 32/64-битной разрядности.

## 4. Установка на рабочем месте

1. Закройте Word, Excel и Visio.
2. Скопируйте папку `office-connector` на рабочий компьютер (или разверните её из общей сетевой папки только для чтения).
3. Откройте PowerShell **от имени администратора**. Скрипт регистрирует COM-классы через RegAsm и создаёт записи надстроек в профиле пользователя, который запускает скрипт. Поэтому запускайте его под той же учётной записью Windows, под которой работает Office.
4. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\office-connector\scripts\install.ps1 -DllPath ".\office-connector\src\DocFlow.OfficeConnector\bin\Release\DocFlow.OfficeConnector.dll"
```

Скрипт регистрирует COM-классы для Word, Excel и Visio и создаёт записи надстроек в HKCU. Разрядность Office определяется по Click-to-Run; если Office установлен через MSI или определение не совпало, проверьте разрядность Office и используйте соответствующий RegAsm из `Framework` (x86) или `Framework64` (x64). Если установлен не весь пакет Office, ненужные записи можно удалить через `uninstall.ps1`.

5. Запустите Word/Excel/Visio. На ленте появится вкладка **DocFlow**.

Если надстройка не появилась, проверьте разрядность Office, путь к DLL, .NET Framework 4.8 и список отключённых надстроек (File → Options → Add-ins → COM Add-ins).

## 5. Первое подключение

1. Откройте любой сохранённый документ.
2. Нажмите **DocFlow → Отправить в хранилище** или **Открыть из хранилища**.
3. Введите базовый URL сервера, например `http://192.168.1.20:8000`.
4. Введите логин и пароль DocFlow.
5. Выберите проект, ветку и папку.

Пароль не записывается в файл конфигурации. Надстройка использует cookie-сессию, выдаваемую самим DocFlow, и держит её в памяти процесса Office. При закрытии всех окон Office сессия в надстройке прекращается; при следующем запуске потребуется авторизация.

## 6. Отправка и обновление

- Нажмите **Отправить в хранилище**.
- Надстройка вызывает Save в активном приложении Office.
- Выберите проект, ветку и папку назначения.
- Можно выбрать существующий документ в списке или оставить режим **Автоматически по имени файла**.
- При выборе существующего документа отправляется новая версия именно этого документа.
- В автоматическом режиме сервер использует имя файла в выбранной папке: если документ с таким именем уже есть в выбранной ветке, создаётся новая версия; если нет — создаётся документ.
- Введите комментарий версии и нажмите **Отправить**.

Если байты файла не изменились, сервер вернёт ответ, что версия не создана.

## 7. Открытие и история версий

1. Нажмите **Открыть из хранилища**.
2. Выберите проект, ветку и папку.
3. Выберите документ — надстройка покажет его версии.
4. Выберите версию и нажмите **Скачать и открыть**.
5. Файл будет сохранён во временную папку пользователя и открыт приложением Windows по умолчанию.

Открытие версии не заменяет текущий открытый документ без отдельного действия пользователя. Если требуется продолжить редактирование загруженной версии, сохраните её под нужным локальным именем.

## 8. Безопасность и эксплуатация

- Используйте персональные учётные записи DocFlow, не общие логины.
- Права на проекты проверяются сервером; надстройка не обходит ACL.
- Сессия передаётся в cookie и не сохраняется в открытом виде на диске.
- Не добавляйте пароль в командную строку, скрипты или сетевые конфигурационные файлы.
- Ограничьте доступ к порту сервера корпоративной подсетью и регулярно делайте резервные копии БД и файлового хранилища.
- При использовании HTTP помните: пароль и содержимое файлов не шифруются на уровне транспорта. Для повышенных требований включите HTTPS.

## 9. Удаление

Закройте Office и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\office-connector\scripts\uninstall.ps1
```

Удаление надстройки не затрагивает документы на сервере DocFlow.

## 10. Диагностика

- `/api/health` недоступен: проверьте адрес, порт, firewall и привязку сервера к LAN-интерфейсу.
- Ошибка 401: повторно войдите в DocFlow, проверьте логин/пароль и активность учётной записи.
- Ошибка 403: у пользователя нет прав записи в проекте/папке или роль наблюдателя.
- Файл не отправляется: проверьте лимит загрузки DocFlow и доступность локального файла.
- Вкладка отсутствует: проверьте COM Add-ins в параметрах Office, HKCU\Software\Microsoft\Office\{Word|Excel|Visio}\Addins и наличие .NET Framework 4.8.
- Для расследования ошибок используйте журнал DocFlow и сообщения диалогов надстройки.

## 11. Что поддерживается

| Приложение | Форматы | Отправка | Получение/версии |
|---|---|---:|---:|
| Word | DOC, DOCX, DOCM, RTF и др. | Да | Да |
| Excel | XLS, XLSX, XLSM, XLSB и др. | Да | Да |
| Visio | VSD, VSDX, VSDM и др. | Да | Да |

Надстройка передаёт бинарный файл без преобразования; поддержка формата определяется установленным Office.
