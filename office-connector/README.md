# DocFlow Office Connector

Локальная интеграция DocFlow с настольными Microsoft Word, Excel и Visio для Windows.

## Возможности
- Кнопки на ленте Office: **DocFlow → Отправить в хранилище** и **Открыть из хранилища**.
- Подключение к серверу по адресу локальной сети (например, `http://192.168.1.20:8000`).
- Авторизация существующей учётной записью DocFlow через серверную сессию.
- Выбор проекта, ветки и папки.
- Обновление существующего документа или создание нового; сервер сам проверяет SHA-256 и не создаёт дубликат неизменившегося файла.
- Просмотр истории версий и загрузка выбранной версии.
- Сохранение текущего документа в Office перед отправкой.
- Единый исходный код для Word, Excel и Visio.

## Состав
- `src/DocFlow.OfficeConnector.sln` — решение Visual Studio.
- `src/DocFlow.OfficeConnector/` — COM add-in, Ribbon и клиент API.
- `scripts/install.ps1` / `scripts/uninstall.ps1` — регистрация надстроек для текущего пользователя Windows.
- `docs/INSTALL_RU.md` — подробная установка и настройка в локальной сети.

## Требования
- Windows 10/11.
- Настольный Microsoft Office для Windows (Word, Excel и/или Visio).
- Visual Studio 2022 с .NET desktop development и .NET Framework 4.8 Developer Pack для сборки.
- Доступ к серверу DocFlow по HTTP/HTTPS из локальной сети.

## Важные ограничения первой версии
- Это Windows COM add-in, не Office web add-in: браузерный Office и macOS не поддерживаются.
- Установка надстройки выполняется отдельно на каждом рабочем месте.
- Для работы с файлами требуется, чтобы документ был сохранён локально. Надстройка сохраняет его перед отправкой.
- Аутентификация использует штатную cookie-сессию DocFlow; пароль не сохраняется в конфигурации. Сессия живёт в памяти процесса Office и действует согласно настройкам сервера.
- Не открывайте HTTP-порт DocFlow в Интернет. Используйте только доверенную LAN/VPN; для сетей с недоверенными устройствами настройте HTTPS.
